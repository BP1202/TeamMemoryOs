# Design System

## Purpose

Build a premium desktop-first AI Operating System interface.

## Design Principles

* Minimal.
* Calm.
* High information density.
* Consistent spacing.
* Accessible contrast.

## Components

* Button
* Card
* Sidebar
* Topbar
* Table
* Dialog
* Empty State
* Loading State

## Rules

Use reusable components before creating new UI.

Never duplicate styling across features.
