# TeamMemoryOS Frontend

The frontend is the AI Workspace for TeamMemoryOS.

## Architecture

* Feature-first architecture.
* React Query for server state.
* Zustand for client state.
* Shadcn UI design system.
* React Flow knowledge graph.
* AI explainability components shared across chat and agents.
