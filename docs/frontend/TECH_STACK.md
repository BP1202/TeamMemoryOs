# TeamMemoryOS Frontend Tech Stack

## Framework

* React 19
* TypeScript
* Vite

## Styling

* Tailwind CSS
* Shadcn UI
* Framer Motion

## State Management

* React Query (Server State)
* Zustand (Client State)
* React Hook Form (Forms)

## Networking

* Axios

## Graph Visualization

* React Flow

## Icons

* Lucide React

## Markdown Rendering

* react-markdown
* rehype-sanitize

## Testing

* Vitest
* React Testing Library
* MSW
* Playwright (Sprint 8.6)

## Rules

* No Redux.
* No Context API for application state.
* No direct fetch calls.
* No inline styles unless animation requires them.
